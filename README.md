# ASR SimEd

**Free 3D model editor for rFactor 2 and Assetto Corsa car mods** — by Alessandro Micali · [ASR Formula](https://asrformula.com)

ASR SimEd opens, edits and converts car models of **rFactor 2** (GMT / GEN / VEH / ANM, S397 json materials) and
**Assetto Corsa** (KN5 / ksanim), with **FBX** and **OBJ** import and export. Everything is drawn live with Direct3D 11,
in a dark interface.

## Download

👉 **[Latest version](https://github.com/asrformula/ASR-SimEd/releases/latest)** — download `ASR_SimEd_x.y.z_date.zip`,
unzip it anywhere and run `AsrSimEd.exe`. No installation needed.

- Windows 10 / 11, 64 bit, DirectX 11 graphics card.
- The first time Windows may show "Windows protected your PC": click **More info** › **Run anyway** (the program is not signed).
- Updates: the program checks this page once a day and installs a new version only after you confirm
  (Help › Check for Updates).

## Features

- rFactor 2: open cars from the .veh (GEN, GenString, upgrades, livery), edit objects and GEN instances, materials and
  texture stages, animated textures, driver animations (.ANM), S397 Material Editor jsons (import / export / edit).
- Assetto Corsa: KN5 materials and shaders, ksanim animations, FBX animations as in KsEditor, persistence .ini.
- Conversions: FBX / KN5 → rFactor 2 GMT (one GMT per object), rFactor 2 → KN5, FBX and OBJ export.
- Editing: move / rotate / scale gizmo and Blender-style keys, pivots, hierarchy, face selection (detach, copy, delete),
  normals, UV tiling, primitives, model checks and data reports.
- Interface and user guide in **English, Italiano, Deutsch, Français, Español, Português (Brasil)**.
- Your files are never overwritten without confirmation, and a `.bak` copy is kept.
